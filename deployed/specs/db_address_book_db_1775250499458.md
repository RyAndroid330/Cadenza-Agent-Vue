# Address Book DB (db)
Description: Store user addresses and bookings
Port: 4101

## Routes
- GET /addresses
- POST /addresses
- GET /addresses/:id
- PUT /addresses/:id
- PATCH /addresses/:id
- DELETE /addresses/:id
- GET /bookings
- POST /bookings
- GET /bookings/:id
- PUT /bookings/:id
- PATCH /bookings/:id
- DELETE /bookings/:id

## Data Stores
- addresses (array)
- bookings (array)
